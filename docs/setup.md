# התקנה

צריך `Python 3.10` ומעלה, ושום דבר אחר.

</div>

```bash
git clone https://github.com/itayco2/AI-Engineering-in-Hebrew
cd AI-Engineering-in-Hebrew
make setup
make gate
```

<div dir="rtl" lang="he" align="right" markdown="1">

הפקודה `make setup` תשתמש ב-`uv` אם הוא מותקן, ואם לא, תיפול חזרה ל-`venv` ול-`pip` שמגיעים עם `Python`. שתי הדרכים עובדות, האחת פשוט מהירה יותר.

הפקודה `make gate` היא הדבר הראשון שכדאי להריץ כשמשהו לא עובד. היא בודקת שהחבילה נטענת, שמודל ה-`embedding` יורד ומצליח להריץ משפט אחד, שכל פרק מצהיר על עצמו נכון, ושכל קובץ נתונים שפרק מבקש קיים. היא נגמרת בפחות מדקה ובדרך כלל אומרת מה הבעיה במקום להיכשל בעשרים דקות במקום מוזר.

## להריץ פרק

</div>

```bash
make run-01      # מריץ את פרק 01 מקצה לקצה
make test        # החבילה עצמה: פונקציות טהורות, בלי מודל
make docs-serve  # האתר הזה, מקומית
```

<div dir="rtl" lang="he" align="right" markdown="1">

## אם רוצים גם את הפרקים שצריכים מודל שפה

הפרקים האלה עובדים כברירת מחדל מתוך תשובות מוקלטות, ולכן הם רצים גם בלי שום מודל מותקן. מי שרוצה להריץ אותם מול מודל אמיתי צריך אחת משתי הדרכים, ושתיהן חינמיות.

הדרך הראשונה היא `Ollama`, שמתקינים בנפרד ומריצים ברקע. זו הדרך הנוחה.

</div>

```bash
ollama pull llama3.2:3b
AIHE_BACKEND=ollama make run-01
```

<div dir="rtl" lang="he" align="right" markdown="1">

הדרך השנייה היא `llama-cpp-python`, שמותקן ישירות מ-`pip` ועובד גם על `Windows` בלי התקנה נוספת. היא מתאימה למי שמעדיף לא להתקין עוד שירות.

</div>

```bash
pip install llama-cpp-python
export AIHE_GGUF=/path/to/a/model.gguf
AIHE_BACKEND=llamacpp make run-01
```

## על "חינם" בכלל

שווה לדעת מה המחיר האמיתי של כל דרך, כי הוא לא תמיד כספי.

מודל מקומי הוא חינם לגמרי, והמחיר שלו הוא זיכרון: מודל בגודל `7B` רוצה בערך `8GB` פנויים. השכבות החינמיות של הספקים הגדולים הן סיפור אחר, אצל חלקן התוכן שנשלח משמש לשיפור המוצר ובני אדם עשויים לראות אותו, ואצל אחרות צריך להסכים לתיעוד כדי לקבל את המודל החינמי. כל זה בסדר לתרגול ולא בסדר לנתונים אמיתיים, ולכן ברירת המחדל כאן היא מקומית.

מי שמשלם על מנוי `Claude` יכול להריץ דרכו קוד לפי התנאים של `Anthropic`, וזו דרך נוספת בלי חשבון נפרד.
