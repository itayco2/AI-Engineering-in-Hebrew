# פרק 04 — הנדסת הקשר

כשהשיחה מתארכת, האינסטינקט הוא לסכם את ההתחלה. הפרק הזה מודד מה זה באמת עולה.

שש עובדות שנשתלות בתחילת שיחה, נקברות תחת פלט של כלים, ואז מתבקשות בחזרה — תחת שלוש אסטרטגיות שונות.

סיכום חסך 67 אחוז מהתווים ואיבד את העובדה בכל שש הפעמים. חיתוך פלט הכלים חסך 47 אחוז ולא איבד כלום. וההסבר לכך הוא ה-`cache`, ואפשר להכריע אותו בהשוואת בתים בלי לקרוא לאף מודל.
